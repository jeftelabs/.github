# JefteLabs — Laboratório de projetos

Este repositório é o espaço central de trabalho dos projetos mantidos pela equipe. Cada projeto pode ficar em sua própria pasta, com seu código, documentação e histórico, enquanto este repositório ajuda a organizar e acompanhar o conjunto.

## Sobre o JefteLabs

JefteLabs reúne pequenos pacotes utilitários usados pela equipe do [ArapucaJS](https://arapucajs.com/). Os pacotes são independentes e atendem a necessidades específicas, desde manipulação de objetos e strings até ferramentas para linha de comando, hooks e monitoramento de arquivos TypeScript.

## Pacotes com manutenção ativa

| Pacote | Descrição |
| --- | --- |
| [object-builder](https://github.com/poppinss/object-builder) | Classe auxiliar para criar objetos com propriedades dinâmicas. |
| [string](https://github.com/poppinss/string) | Funções auxiliares para operações com strings. |
| [utils](https://github.com/poppinss/utils) | Utilitários compartilhados pelos pacotes AdonisJS, Edge e Japa. |
| [cliui](https://github.com/poppinss/cliui) | Kit de interface para aplicações de linha de comando. |
| [youch](https://github.com/poppinss/youch) | Formatador de erros para exibição legível. |
| [hooks](https://github.com/poppinss/hooks) | Implementação simples para executar hooks em torno de eventos. |
| [middleware](https://github.com/poppinss/middleware) | Implementação do padrão de cadeia de responsabilidade. |
| [oauth-client](https://github.com/poppinss/oauth-client) | Cliente independente de framework para fluxos de autenticação OAuth. |
| [file-generator](https://github.com/poppinss/file-generator) | Gera arquivos de teste em memória com tamanhos variados. |
| [intl-formatter](https://github.com/poppinss/intl-formatter) | API com memoização para recursos `Intl` do Node.js. |
| [macroable](https://github.com/poppinss/macroable) | Permite estender classes com macros e getters. |
| [prompts](https://github.com/poppinss/prompts) | Wrapper do Enquirer com melhor suporte a testes. |
| [colors](https://github.com/poppinss/colors) | Wrapper do Kleur com melhor suporte a testes. |
| [chokidar-ts](https://github.com/poppinss/chokidar-ts) | Monitor de arquivos para projetos TypeScript. |
